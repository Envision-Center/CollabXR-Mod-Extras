CollabXR Mod Extras
======================

The Mod Extras is a Unity package that allows `CollabXR`_ users add certain functionalities to their own content and visualizations.

Quick Start
---------------------

* In the Unity Editor, open your Package Manager.
* Press **Add > Install package from git URL...** and enter ``https://github.com/Envision-Center/CollabXR-Mod-Extras.git#stable``
* See the `docs`_ for usage instructions!

.. _CollabXR: https://envision.center/collabxr
.. _docs: https://envision-center.github.io/CollabXR-Documentation/modextras.html
